# source/ — stage 1 · the originals

The inputs the master came from: a traced photo, a commissioned render, a `.ttf`, an upscaled scan, a
reference the artwork was drawn against.

<br>

## The one rule

> 🔒 **Nothing is ever deleted from here.**

This is **the only unreproducible content in the entire brand system.** Every other file — the master's
lockups, the PNGs, the icon ladder, the shipped copies, the in-app component — can be regenerated by
re-running a script. What is in this folder cannot be regenerated by anything: it is what everything else
was derived *from*.

A file here that looks obsolete is not obsolete. It looks obsolete because its derivative superseded it,
which is exactly the relationship that makes it worth keeping.

<br>

## What belongs here

- The original commissioned or photographed asset, **at full resolution**, in whatever format it arrived.
- Font files the wordmark is set in.
- Anything a human handed over that the artwork was built from.

## What must never happen to it

| Never | Why |
|---|---|
| delete a file | a file here is **never deleted** — it is unreproducible, see above |
| edit a file in place | it stops being the original the moment you do |
| ship it | 🔒 full-resolution originals must never be served |

<br>

## Status

**Empty** — no artwork has been commissioned or authored yet. When it is, the original lands here
**before** the master is drawn, and stays.
